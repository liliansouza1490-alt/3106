# 3106 3.1.10 测试版（未发布）

发布日期：2026-11-10

3.1.10 是针对两个实际 `.tendies` 包（`枯木逢春`、`四季双模式`）的修复测试构建，**尚未发布到 GitHub**。

## 根因与修复

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 两个包导入仍报 `unsafeArchive` | 包本身完全正常：两个 ZIP 共 444/462 个条目，C 解包器逐条解压 0 失败。失败发生在解包后的路径校验：`isContained` 用原始字符串比较，临时目录是 `/var/...`，枚举出的子路径是 `/private/var/...`，被误判为越界 | `isContained` 统一走 `LaunchServicesStore.isPath`，先 canonical 化再比较；新增 `/var` 与 `/private/var` 混用的回归测试 |
| 设备端树里有 `descriptors`，扫描仍报没有 | 直接对 `.../61/Extensions/...` 调 `fileExists`/`contentsOfDirectory` 被沙箱拒绝；`FileManager.enumerator` 可以正常遍历。旧递归逻辑又用相对路径/深度判断，进一步跳过了 `Extensions` | 布局发现改为**枚举器优先**，直接寻找任意 `descriptors` 目录，不再依赖逐路径 `fileExists`；旧的 generation/synthetic 逻辑保留为兜底 |
| 清理切文件页卡 2-3 秒 | 每次 reload 清空 LaunchServices 快照、重复解析 18MB 数据库、重复 6-13 秒文件枚举，并激活 491 个 MHA 候选 | 3.1.9 已加入 10 秒缓存、快照复用和 MHA 跳过条件 |

## 验证方法

1. 安装 3.1.10，重新导入 `枯木逢春.tendies`、`四季双模式.tendies`。
   - 成功：日志应出现 `wallpaper: enumerator found ... descriptor directories`、`wallpaper: enumerated layout generation=61 ...`、`wallpaper: install ...`。
   - 失败：把新的 `wallpaper: import rejected ... key=... error=...` 行发回；现在剩余拒绝点都有具体诊断。
2. 清理页开始扫描后切到文件页，应明显变快；日志应出现 `browser: filesystem cache hit ...` 和 `browser: skipping MHA scan ...`。
3. 设置页版本应显示 `3.1.10`，不再弹更新提示。
