# 3106 3.1.6 正式版

发布日期：2026-11-10

3106 3.1.6 恢复并接入 3105 2.0 的文件夹收藏夹功能。

## 更新内容

| 类别 | 主要内容 |
| --- | --- |
| 收藏 | 文件浏览器长按文件夹，选择“添加到收藏夹”；再次长按可移除 |
| 收藏 | 与 3105 2.0 一致：文件标签页顶部内联“收藏夹”Section，直接列出收藏文件夹名称与完整路径；点击在新标签页打开，左滑移除 |
| 收藏 | 不设独立收藏页面，也不在文件首页“应用数据”下方增加入口 |
| 兼容 | 沿用 3105 2.0 的 `fileBrowserFavorites` JSON（`id` / `path` / `name`），升级后旧收藏可直接读取 |
| 健壮性 | 收藏路径归一化：`/var` 与 `/private/var` 视为同一路径，忽略尾部斜杠，重复路径自动去重 |
| 健壮性 | 收藏文件夹自动解析所属容器根目录，打开时使用正确的沙箱授权边界 |

## 使用方式

1. 在文件浏览器中长按任意文件夹。
2. 选择“添加到收藏夹”。
3. 点右上角的文件标签页按钮，在列表顶部的“收藏夹”Section 中直接查看收藏文件夹；点击即可在新标签页打开，左滑移除。

## 验证方法

1. 长按文件夹应出现“添加到收藏夹”；收藏后再次长按应变为“从收藏夹移除”。
2. 右上角文件标签页应在最上方显示“收藏夹”Section，行内同时显示名称与路径；其下才是打开的文件标签。
3. 文件首页“应用数据”下方不应再出现独立的收藏入口。
4. 左滑收藏行应可移除；重启应用后收藏仍存在。
5. 从 3105 2.0 升级时，旧的 `fileBrowserFavorites` 数据应自动出现在收藏夹中。
