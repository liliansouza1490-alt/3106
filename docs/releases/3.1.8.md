# 3106 3.1.8 正式版

发布日期：2026-11-10

3106 3.1.8 修复三个反馈问题：已安装最新版仍提示更新、清理扫描时切换底栏卡死、动态 `.tendies` 壁纸包导入失败。

## 更新内容

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 已安装最新版仍提示更新 | `Info.plist` 里的 `AppReleaseDisplayVersion` 仍是 3.1.4，更新检查优先读它 | 移除该字段，统一使用 `CFBundleShortVersionString`；测试脚本增加版本字段一致性检查 |
| 清理扫描时切底栏卡死 | 每处理一个应用就向主线程发布一次全量列表，几百个应用会灌爆主线程 | 发布节流到每秒最多 4 次，每批扫描结束时强制刷新一次 |
| 动态壁纸包导入失败 / 扫描不到 descriptors | `storeURL` 使用 `/var`，`FileManager` 枚举返回 `/private/var`，递归布局按错误前缀计算相对路径，整棵 `Extensions` 被跳过 | 扫描前解析符号链接；相对路径同时兼容两种拼写；包内 `container` 的根目录比较也改为解析后比较 |
| 导入失败无法定位 | 只记录“import rejected” | 日志增加错误 key 与完整错误信息 |

## 验证方法

1. 安装后打开应用，不应再出现“发现新版本”弹窗；设置页版本应显示 `3.1.8`。
2. 进入清理页开始扫描，随后切换底栏其他页面，不应卡死；返回清理页后列表与底部“已加载 N 个应用”应继续更新。
3. 重新导入之前失败的动态 `.tendies` 包。日志应出现 `wallpaper: scan root=/private/var/...`、`wallpaper: layout generation=...`；若仍失败，日志会给出 `wallpaper: import rejected <文件> key=... error=...`。
4. 安装壁纸后按提示关闭 PosterBoard，再检查锁屏壁纸选择器。
