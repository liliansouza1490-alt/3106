# 3.1.4 正式版

发布日期：2026-11-10

3106 3.1.4 是首个正式版。它基于 3105 2.0 源码，完成 iOS 27 适配、`worse_query` 沙箱后端、可配置底栏、清理器与壁纸修复，并统一更名为 3106。

## 更新内容

| 版本 | 类别 | 主要内容 |
| --- | --- | --- |
| **3.1.4** | 清理器 | 删除阶段改用扫描记录的真实容器路径，不再按 bundleID 重解析；`FileManager` 安全删除，拒绝跳出容器的 Caches 符号链接 |
| 3.1.3 | 壁纸 | PosterBoard 扫描器支持 27.3 的嵌套/非标准布局；递归查找 `descriptors`，必要时在真机上创建所需扩展目录 |
| 3.1.2 | 清理器 / 壁纸 | 清理测量改用 `FileManager`；壁纸按 PosterBoard 存储目录反查容器；清理页常驻设置齿轮 |
| 3.1.1 | 容器访问 | 清理器加入文件系统枚举与容器索引回退；壁纸扫描、探针、安装、重置逐目录授权 |
| 3.1.0 | 应用 | 可配置底栏（最多 5 槽，首页固定）；开发者模式默认开启；移除推广与致谢；中文 README + 英文入口 |

## 安装与签名

| 签名方式 | App Group | 说明 |
| --- | --- | --- |
| AltStore / SideStore / Sideloadly + Apple ID | 自动创建 | 推荐，免费 Apple ID 即可 |
| 自有开发者账号 | 显式 App ID + App Groups | 需专用描述文件 |
| 证书 + 通配符 profile | 不支持 | `worse_query` 会报 “No App Group” |
| LiveContainer | 取决于签名环境 | 在应用内 设置 → App Group 检查 |

Bundle ID：`com.qingtang.3106`。iOS 26.7+ / 27.x 必须有 App Group；iOS 17/18 不需要，但仍使用内核链路。

## 已知限制

- iOS 27.3 beta 1 为实验性支持；不同 beta build 的 PosterBoard 布局可能继续变化。
- iOS 26/27 只提供容器级沙箱扩展，不提供 root、内核 R/W 或完整文件系统权限。
- System Data 在 iOS 27 上仅可列目录，内容由 root 所有。
- iOS 17/18 的内核链路仍需手动启用。
