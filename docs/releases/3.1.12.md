# 3.1.12 正式版

发布日期：2026-11-10

3.1.12 是 3.1.7 之后的正式累积更新，包含 3.1.8–3.1.12 的全部修复。主要解决：壁纸导入/扫描失败、已安装最新版仍提示更新、清理页切到文件页卡顿。

## 自 3.1.7 以来的更新

### 更新提示

- 修复已安装最新版仍弹“发现新版本”。原因是 `Info.plist` 里残留 `AppReleaseDisplayVersion = 3.1.4`，更新检查优先读了它；该字段已移除，统一使用 `CFBundleShortVersionString`。
- 启动日志第一行现在显示版本与 build，例如 `app: 3106 3.1.12 (16) launching`，避免装错旧包。

### 清理器

- 清理扫描改为**逐应用加载**，列表边扫描边出现。
- 底部实时显示：`已加载 N 个应用 · M 个有可清理数据…`。
- 发布节流到每秒最多 4 次，避免几百个应用瞬间刷爆主线程导致切页卡死。
- LaunchServices 快照、标识符列表、文件系统应用列表复用 10 秒；普通切页不再重复解析 18MB 数据库和 6–13 秒文件枚举。
- LS 已识别 ≥75% 容器时跳过 491 个 MHA 候选激活，显著缩短文件页首次加载。

### 壁纸

- `.tendies` ZIP 兼容 Windows/中文包：GB18030 文件名、反斜杠路径、重复目录项、768MB 视频条目。
- 修复 `/var` 与 `/private/var` 被当成两棵目录树的问题：扫描、包校验、路径包含检查全部 canonical 化。
- 包检查器不再因为单个路径/symlink 异常整包抛 `unsafeArchive`；改为记录并跳过问题项。
- 设备端 descriptor 发现改用 tree 枚举收集，并在 tree 之后增加路径后缀枚举兜底；不再出现“树里明明有 descriptors、扫描却说没有”。
- 保留 3.1.7 的 Mercury 原目录名、`VideoCAML` 视频壁纸映射、散装 descriptor 文件支持与安装后打开 PosterBoard 刷新。

### 应用数据与收藏（3.1.7 已包含，本版继续保留）

- 应用数据浏览器恢复全部容器，未识别容器单独分组、可浏览但只读。
- 收藏夹：长按文件夹收藏，文件标签页顶部直接列出收藏路径；点击收藏会先授权容器根，不再出现空列表。
- 兼容 3105 2.0 的 `fileBrowserFavorites` 数据。

## 安装与签名

- AltStore / SideStore / Sideloadly + Apple ID：推荐，需 App Group。
- 自有开发者账号：显式 App ID + App Groups。
- 通配符 profile 不支持（无法携带 App Group）。

## 升级说明

- 从 3.1.7 或 3.1.8–3.1.11 测试版升级可直接覆盖安装，收藏、补丁与壁纸数据保留。
- 首次启动后确认日志第一行是 `3.1.12 (16)`；若不是，说明装到了旧 IPA。

## 已知限制

- PosterBoard 壁纸列表刷新仍依赖系统进程；安装后请按提示关闭 PosterBoard 或重新打开锁屏壁纸选择器。
- iOS 27.3 beta 的 PosterBoard 布局可能继续变化；诊断日志会输出实际 generation 与 provider 列表。
- 壁纸数量建议不超过 15 个 descriptor。
