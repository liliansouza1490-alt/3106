# 3106 3.1.5 正式版

发布日期：2026-11-10

3106 3.1.5 修复应用数据浏览器“显示不全”的回归：3106 改名后 bundle id 变为 `com.qingtang.3106`，但 MCM 桥仍硬性要求 `com.apple.mobile.MobileHouseArrest`，导致 MCM 枚举与路径解析全部失败；身份解析失败的 UUID 容器又被展示策略静默隐藏。

## 更新内容

| 类别 | 主要内容 |
| --- | --- |
| 应用数据 | 移除 `MCMActivateContainerPath` 的 MHA 硬门禁；MCM 失败时回退到 LaunchServices 数据库与文件系统扫描 |
| 应用数据 | 新增 LaunchServices `bdsl` CSStore 解析器，直接建立“容器路径 ↔ bundle id”映射，覆盖 26 / 27.0 / 27.2 布局 |
| 应用数据 | 从 Internal Daemon 容器读取 lsd 数据库；文件系统扫描与 LS 容器列表取并集 |
| 应用数据 | 未识别容器进入独立分组，名称为 `Container <UUID 前 8 位>`，可浏览但只读（隐藏导入、新建、粘贴、重命名、删除、替换、解压、补丁创建） |
| 应用数据 | 数据源改为并集：workspace + MobileInstallation、`allApplications` + `allInstalledApplications`、MobileInstallation 的 Any/User/System |
| 清理器 | 未识别容器同样测量 `Library/Caches` 与 `tmp`，显示大小但带锁、不可勾选、不可清理 |
| 稳定性 | MHA 候选扫描期间不再用“仅已识别”结果覆盖列表，避免浏览过程中列表突然变短 |

## 验证方法

1. 打开应用数据浏览器，日志应出现：
   - `browser: LaunchServices layout=... containers=... names=...`
   - `browser: LS/API apps=... missingContainer=... launchServices=...`
   - `browser: filesystem accepted ...`
   - `browser: inferred ... unresolved=...`
2. 对比 `应用数据` 列表中的应用数量与文件系统容器数量；未识别容器应出现在独立分组。
3. 点击未识别容器应能浏览数据，但不显示导入/新建/重命名/删除/替换/补丁按钮。
4. 清理器中未识别容器显示大小和锁图标，无法勾选。

## 已知限制

- iOS 27.3 beta 1 的 LaunchServices 记录布局可能继续变化；解析器会输出布局与映射统计，必要时新增一行布局定义即可。
- 未识别容器只读；识别身份后可正常使用补丁与清理。
- iOS 26/27 仍只提供容器级沙箱扩展，不提供 root 或完整文件系统权限。
