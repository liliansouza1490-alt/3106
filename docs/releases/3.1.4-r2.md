## 安装与签名

| 签名方式 | App Group | 说明 |
| --- | --- | --- |
| AltStore / SideStore / Sideloadly + Apple ID | 自动创建 | 推荐，免费 Apple ID 即可 |
| 自有开发者账号 | 显式 App ID + App Groups | 需专用描述文件 |
| 证书 + 通配符 profile | 不支持 | `worse_query` 会报 “No App Group” |
| LiveContainer | 取决于签名环境 | 在应用内 设置 → App Group 检查 |

Bundle ID：`com.qingtang.3106`。iOS 26.7+ / 27.x 必须有 App Group；iOS 17/18 不需要，但仍使用内核链路。

## 已知限制

- iOS 27.3 beta 1 为实验性支持；不同 beta build 的 PosterBoard 布局可能继续变化。
- iOS 26/27 只提供容器级沙箱扩展，不提供 root、内核 R/W 或完整文件系统权限。
- System Data 在 iOS 27 上仅可列目录，内容由 root 所有。
- iOS 17/18 的内核链路仍需手动启用。
